# 📊 Business Insight Agent

A multilingual AI-powered Business Intelligence (BI) agent that allows users to ask business-related questions in natural language and get instant insights using visual charts and human-readable summaries.

Built for the **HOLON x KBI AI Agents Hackathon 2025**.

---

## 🚀 Features

- 💬 Chat-based query interface
- 🌐 Multilingual support (English, Mandarin, Cantonese)
- 📈 Auto-generated business insights with data visualizations
- 🧠 Uses LLMs to understand and respond to user queries
- 🔍 Matches queries to stored templates and analytics data
- 📊 Integrates with mock Google Analytics data

---

## 🛠️ Tech Stack

| Layer       | Technology             |
|------------|------------------------|
| Frontend   | React.js               |
| Backend    | FastAPI                |
| AI Engine  | LangChain + Qwen / DeepSeek (LLMs) |
| Data       | Pandas / DuckDB        |
| Storage    | SQLite / CSV / JSON    |
| Visualization | Plotly / ECharts     |
